## Hi, I'm Citra

Information Systems graduate. I build web apps and data dashboards that turn public datasets into something people can read and act on, mostly for environmental and social programs in Indonesia.

Currently a consultant at Yayasan Madani Berkelanjutan.

### What I work on

- Data dashboards for monitoring programs (wildfire, village data, sustainability assessments)
- Web apps with React, Next.js, and PostgreSQL / Supabase
- Websites for NGOs: setup, maintenance, security hardening, email deliverability
